## 1. Fixture:假的換回真的(`474cc55`)

分支上原本那六份**是寫出來的不是錄的**:

```json
"model": "claude-fixture"      "session_id": "sess-multi"
"tool_use_id": "toolu_multi_1" "duration_ms": 5      "total_cost_usd": 0.0
```

沒有任何欄位是從真檔塗改來的。它在分類上夠用(四種 `outcome` 跟真資料一致),
但**截斷邏輯永遠碰不到**(`truncate.py` 一輪 60,000 字元,六份假的加起來 5.5 KB),
而且**Summarizer 會對著理想輸入調 prompt**。

原本改成合成的理由是怕帶進機敏資料。實際掃過六份:

| 顧慮 | 實際 |
|---|---|
| credentials | **0** |
| authorization headers | **0**(SDK 不放進 message stream) |
| raw chain-of-thought | `ThinkingBlock` 有,但 `thinking` 是空字串 |
| private command paths | **每檔 3 處** ← 只有這條成立 |

改成就地打碼,`tools/redact_fixtures.py` 只換三種本機字串
(`<workspace>` / `<project>` / `<home>`),其餘一律保留。
腳本會先確認「不打碼就重寫」能 byte 級還原原檔,不成立就拒絕寫入。

| | 之後 |
|---|---|
| 大小 | 439–1,448 B → 7,367–17,612 B |
| model | `claude-fixture` → `claude-opus-4-8` |
| cost | `0.0` → `0.014`–`0.178` |

`tools/record_run.py` 現在也在**寫入當下**打碼,未打碼的內容一次都不會落地。

## 2. 模板 linter:我的規則錯了(`042cbb5`)

`lint_templates.py` 原本**禁止** `WEB-SQLI` 這種前綴寫法,對 repo 自己的 5 份模板噴
**114 個錯**。動機是規劃書 §7.3.6,但它跟凍結的合約牴觸:
`spec/template.schema.json` 的 `^[A-Z0-9]+-[A-Z0-9-]+$` **強制**要有前綴。**合約贏。**

改成結構直接餵給 schema 驗,只保留 schema 表達不了的:`id` 與檔名相同、
`general` 分節存在、分節不重複、單檔 ID 唯一、**跨檔同 ID 必須同 title**。

跑完會多印一行,把代價攤開:

```
133 個 guess ID,跨檔共用 0 個 —— §7.3.6「相同 technique ID 可保留 tried state」
在現行命名下永遠不會觸發。
```

## 4. Client 補齊八個端點(`4ccd202`)

原本只有 6/8,缺 `mutate` 與 `template`。

這兩個**刻意不進 `MemoryClient` Protocol** —— 它們是人類 override 的路(§8.6、§10.1),
`AgentLoop` 只認 Protocol,所以它**在結構上就沒有能力改白板**,比註解可靠。
`test_loop_facing_protocol_cannot_mutate` 把這個邊界釘住。

新增 `tests/test_memory_client.py`:用 `httpx.MockTransport` 攔請求,
送出去的 body 直接餵給 spec 裡的 `MemoryMutation` / `TemplateChangeRequest` 驗。
