# 授權說明

本專案採用單一 custom license：

```text
SMOKING ELEPHANT SLOP PUBLIC LICENSE
Version 1.0, July 2026
```

簡稱：

```text
SESPL-1.0
```

工具與 SPDX-like metadata 建議表示為：

```text
LicenseRef-SESPL-1.0
```

## 性質

SESPL-1.0 是類 WTFPL 的 permissive custom license。核心授權條款是：

```text
DO WHATEVER THE FUCK YOU WANT WITH THIS SLOP.
```

它不是 reciprocal/copyleft license，沒有要求：

- 衍生作品必須使用同一授權；
- 發布修改版時必須公開原始碼；
- 對下游加入 share-alike 義務。

`LICENSE` 中的：

```text
Copyleft (C) 2026 Smoking Elephant Slopper
```

是風格化署名，不改變授權性質，也不建立 reciprocal/copyleft 義務。

## Preamble

`NON-BINDING ELEPHANT PREAMBLE` 是非拘束性的幽默前言，不施加任何條件、限制、義務或 elephant-related requirement。

實際具有授權意圖的部分是：

- `TERMS AND CONDITIONS FOR COPYING, DISTRIBUTION AND MODIFICATION`
- `NO WARRANTY`

## OSI / SPDX 狀態

SESPL-1.0 是 custom license：

- 不是 OSI-approved license；
- 不在 SPDX License List；
- 不應宣稱為 OSI-approved open source license；
- 若工具需要 license identifier，使用 `LicenseRef-SESPL-1.0`。

## 下游注意事項

因為 SESPL-1.0 是 custom license，部分企業、套件索引、合規掃描工具可能會顯示 unknown/custom license。

需要正式合規判斷的使用者應自行審查 `LICENSE` 全文。
