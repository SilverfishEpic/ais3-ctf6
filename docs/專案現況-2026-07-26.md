## 環境注意事項

- **`pyproject.toml` 要 Python >= 3.12**,舊的 3.11 venv 要重建
- **Windows 上有 47 個測試會誤報**。`tests/conftest.py` 的 `_no_network` 把
  `socket.connect` patch 掉,而 Windows 的 `ProactorEventLoop` 自我管線用
  `socket.socketpair()`(內部就是 `connect()`)→ 所有 async 測試被自己的守衛擋死。
  Linux 走 `AF_UNIX` 不會踩 —— 同樣那 47 個測試在 Linux 上 **47 passed**。
  修法是讓守衛放行 loopback,三行。
- 開發建議用 **WSL**(實測 Ubuntu 26.04 / Python 3.14.4 全綠)
